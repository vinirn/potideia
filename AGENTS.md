# Instruções para alterações no Potideia

- Ao concluir qualquer mudança no jogo, verifique os arquivos alterados, crie um commit e faça push para o GitHub. Não deixe mudanças do jogo apenas no repositório local.
- Mantenha a versão exibida abaixo do título POTIDEIA coerente com a versão publicada. Ao lançar uma nova versão, atualize `GAME_VERSION` em `app.js`, registre a mudança no `CHANGELOG.md` e publique a tag e a release correspondentes no GitHub.
